⭐ Enigma-Grid
Interactive 23×23 XOR-based encryption simulator with animated grid, glowing particles, and real-time key visualization.
---
🧩 Overview
Enigma-Grid is an interactive encryption playground inspired by the WWII Enigma machine—modernized into a glowing cyber-grid.
A dynamic 23×23 dot matrix generates a unique binary seed, which encrypts any message using XOR logic.
It visually demonstrates how a binary key changes the ciphertext in real time.
Perfect for:
Learning basic encryption concepts
Exploring XOR-based logic
Teaching binary visualization
Creating fun cryptography experiments
---
🚀 Features
✔ 23×23 dynamic grid (auto-generated XOR seed)
✔ Realtime encryption (XOR logic → Base64 output)
✔ Seed Reveal / Hide toggle
✔ Copy buttons for all fields
✔ Particle background animation (Canvas)
✔ Smooth GSAP-based transitions
✔ Fully responsive, neon-cyber UI
